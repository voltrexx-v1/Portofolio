# 👋 Personal Portofolio

Website portfolio pribadi yang menampilkan profil, keahlian, proyek, dan informasi kontak saya.

🌐 **Live Demo**
https://voltrexx-v1.github.io/Portofolio/

---

## 📌 Tentang Project

Website ini dibuat sebagai media untuk memperkenalkan diri, menampilkan kemampuan di bidang software development, serta mendokumentasikan berbagai project yang pernah saya kerjakan.

Portfolio ini dirancang dengan tampilan modern, responsif, dan mudah digunakan pada berbagai ukuran perangkat.

## 🚀 Instalasi

Clone repository

```bash
git clone https://github.com/voltrexx-v1/Portofolio.git
```

Masuk ke folder project

```bash
cd Portofolio
```

Install dependency

```bash
npm install
```

Jalankan project

```bash
npm run dev
```

Build production

```bash
npm run build
```
